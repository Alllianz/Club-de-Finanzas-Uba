# Sesion de trabajo (obligatorio)

Antes de empezar cualquier cambio, preguntar siempre:

- "Estas trabajando desde Desktop o MacBook?"

Luego ejecutar checklist rapido:

1. Confirmar rama y estado git.
2. Confirmar estado de migraciones Prisma en backend.
3. Confirmar que el cliente Prisma este generado.
4. Confirmar que frontend apunta al backend correcto (`NEXT_PUBLIC_API_URL`).

Objetivo: evitar drift de esquema/modelos entre equipos.
